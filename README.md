# TryHackMe Reflections

## Overview

This repository is my open learning log for TryHackMe.

I created this repo to keep track of my cybersecurity learning, document what I practice, and encourage myself to stay consistent. The goal is not just to maintain a streak, but to actually understand what I am learning and connect it to real-world cybersecurity, networking, infrastructure, and security operations concepts.

This repo is part of my larger journey of building practical skills through:

- TryHackMe rooms
- Daily learning reflections
- GitHub commits
- Cybersecurity notes
- Home lab projects
- ISC2 CC preparation
- Network and infrastructure security practice

## Why This Repo Exists

I wanted a place where I could document my learning openly instead of just completing rooms and forgetting what I learned.

This repository helps me:

- Stay accountable
- Maintain consistency
- Track my TryHackMe streak
- Reflect on what I learned each day
- Build a habit of technical writing
- Connect TryHackMe concepts to my home lab and career goals
- Create visible proof of continuous learning
